사이트 소개

#붉은사막 쇼츠·공략글 아카이브는 게임 「Crimson Desert(붉은사막)」를 좋아하는 개인이 취미로 만든 비영리 팬 프로젝트입니다. 펄어비스(Pearl Abyss) 또는 관련 회사와 아무런 공식적인 관계가 없습니다.

이 사이트가 하는 일

유튜브에 올라오는 붉은사막 관련 쇼츠 영상과, 웹문서·블로그·카페에 올라오는 공략글을 자동으로 모아 한 화면에서 볼 수 있도록 정리합니다. 영상은 유튜브가 공식 제공하는 플레이어로 재생되며, 공략글은 제목과 짧은 요약만 보여드리고 클릭하면 항상 원문으로 이동합니다. 영상과 글의 저작권은 각 제작자에게 있으며, 이 사이트는 원문을 복제하거나 재배포하지 않습니다.

자동 갱신

문의

저작권 관련 삭제 요청이나 기타 문의는 GitHub 저장소의 Issues를 통해 남겨주시면 확인 후 조치하겠습니다.

개인정보처리방침

본 사이트(이하 "사이트")는 이용자의 개인정보를 소중히 여기며, 다음과 같이 개인정보처리방침을 안내합니다.

1. 수집하는 정보

사이트는 별도의 회원가입이나 로그인 기능이 없으며, 이름·이메일 등 개인을 식별할 수 있는 정보를 직접 수집하지 않습니다. 실시간 검색 기능을 사용하기 위해 입력하는 API 키는 이용자의 브라우저(localStorage)에만 저장되며, 사이트 운영자나 서버로 전송되지 않습니다.

2. 광고 및 쿠키

사이트는 Google AdSense를 통해 광고를 게재할 수 있습니다. Google을 비롯한 제3자 광고 제공업체는 쿠키를 사용해 이용자가 이 사이트 또는 다른 사이트를 방문한 기록을 바탕으로 광고를 게재할 수 있습니다. Google의 광고 쿠키 사용에 대한 자세한 내용과 맞춤 광고 설정 변경은 Google 광고 설정 페이지에서 확인할 수 있습니다.

3. 자동 수집 정보

웹사이트 운영 및 오류 확인을 위해 호스팅 서비스(GitHub Pages) 또는 방문 분석 도구를 통해 IP 주소, 브라우저 종류, 방문 페이지 등 비식별 접속 기록이 자동으로 수집될 수 있습니다.

4. 아동의 개인정보

사이트는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

5. 방침 변경

본 개인정보처리방침은 관련 법령이나 서비스 변경에 따라 수정될 수 있으며, 변경 시 이 페이지를 통해 안내합니다.

6. 문의

개인정보 관련 문의는 GitHub 저장소의 Issues를 통해 남겨주시기 바랍니다.
